CONTROL DESIGN · NOT A CERTIFICATION

Security overview

Suadence is designed around server-resolved organization membership, database row-level security, least privilege, evidence lineage, and human approval for generated intelligence.

Application controls

  • Supabase authentication independent of ChatGPT accounts.
  • Organization-scoped records and role-aware server authorization.
  • Server-only AI, storage, connector, and scanner credentials.
  • Consent gating, prompt-injection resistance, file validation, and commercial scanning.
  • Append-only action metadata and lineage-aware deletion workflows.

Launch gates

Penetration testing, incident-response ownership, backup restoration, access reviews, vulnerability management, and any claimed certification must be completed before general availability.

Security questions require a designated production security contact.
